Final year project by Yusuf Paul (U21CS1005), Department of Computer Science, Ahmadu Bello University, Zaria.
Supervised by Mal. I.E. Umar.

## Repository structure

Casuak-Workforce-Mgt-System_ABU/

└── README.md

## Tech stack

- Frontend: React
- Backend: Node.js, Express
- Database: PostgreSQL
- Methodology: Iterative development
